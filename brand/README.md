# Pakka brand

**Idea:** a voice (the bars) that ends in a check: *the call that makes the order pakka.*
No phone handset on purpose. Competing apps already use phone + check.

## Files

| File | Use it for |
| --- | --- |
| `pakka-icon-square.svg` / `pakka-icon-1200.png` | Shopify App Store app icon (1200×1200, full bleed; Shopify rounds the corners) |
| `pakka-icon.svg` / `pakka-icon-512.png` | Rounded icon for social profiles, docs, favicons |
| `pakka-logo.svg` / `pakka-logo.png` | Icon + wordmark on light backgrounds |
| `pakka-logo-dark.svg` / `pakka-logo-dark.png` | Icon + wordmark on dark backgrounds |
| `pakka-wordmark.svg` | Wordmark only |

The SVGs are the source of truth. PNGs are exports.

## Colors

| Name | Hex | Where |
| --- | --- | --- |
| Pakka Blue (light) | `#4A8BEA` | Icon gradient start |
| Pakka Blue | `#2C6ECB` | Main brand color. Same as Polaris info blue, so it matches the app UI |
| Pakka Blue (deep) | `#1D4E9E` | Icon gradient end |
| Ink | `#1F2124` | Wordmark on light backgrounds |
| White | `#FFFFFF` | Icon mark, wordmark on dark backgrounds |

## Wordmark

Hand-drawn from circles and straight strokes (no font), so it's unique and needs no
font license. Always lowercase: **pakka**. In sentences, write the name as "Pakka".

## Don't

- Don't recolor the icon or put the mark on a non-blue background.
- Don't add a phone handset or extra text inside the icon.
- Don't stretch it. Scale proportionally, and keep clear space around it of at least
  half the icon's corner radius.
